## Cómo ejecutar
> Recomendación: usa la extencion de Live Server en VSCode o Python3 -m http.server \<PUERTO>.

### Opción A: VS Code Live Server
1. Abre la carpeta del repo en VS Code.
2. Instala la extensión **Live Server**.
3. Abre `src/index.html` → clic derecho → **Open with Live Server**.

### Opción B: Python
1. En terminal, entra a la carpeta `src/`:
   ```bash
   cd src
   ```
2. Ejecuta un servidor:
   - macOS/Linux:
     ```bash
     python3 -m http.server 5500
     ```
   - Windows:
     ```bash
     py -m http.server 5500
     ```
3. Abre en tu navegador:
   - `http://localhost:5500/`
